# Camera Showcase

Standalone interactive 3D camera demo. The index.html file embeds its scripts and assets.

## Vercel

Import this repository, choose Framework Preset: Other, and keep the repository root as Root Directory. vercel.json serves the static files without installation or build steps.

## Update

Replace index.html with Camera-Showcase.html from the source project, commit and push. Connected Vercel projects deploy automatically.
